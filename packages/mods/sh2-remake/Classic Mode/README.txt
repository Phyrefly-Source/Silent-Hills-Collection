Silent Hill 2 (2024) - Classic Mode 0.0.1 (5 Nov 2026)
======================================================
Fixed-camera mode. Turn it on and off from the Silent Hills launcher: Silent Hill 2 (2024) > Mods >
Classic Mode. Off removes every file the mod installed; the game is then exactly as Steam installed it.

Files it installs
  Classic\ClassicMode.ini      settings ([Enhanced] Enabled is the master switch; F7 in game)
  Classic\shots\*.json         the camera shots, one file per map
  (next builds) SHProto\Binaries\Win64\dwmapi.dll and the mod DLL
