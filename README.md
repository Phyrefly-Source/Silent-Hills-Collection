# Silent Hills Collection

Launcher for the classic Silent Hill games (Godot 4.7). Builds are published as
GitHub releases on this repo; the launcher updates itself from them.

- `launcher/` — the Godot project
- `packaging/` — installer script (Inno Setup), AppImage bits, `package.py`
- `updater/` — notes on the in-app update check and install
- `dist/` — files shipped beside the binary
- `docs/RELEASING.md` — how to cut a major build
